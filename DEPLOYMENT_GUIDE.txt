AUTOMATIC DEPLOYMENT
The workflow .github/workflows/deploy-cloudflare.yml runs on pushes to main.
It can also be started from GitHub Actions using Run workflow on main.
It installs the locked dependencies, checks and builds the site, deploys the
existing Worker, and compares the live pages and assets with the built files.
The workflow uses Node.js 24 and the Wrangler version in package-lock.json.
Only one production deployment runs at a time.

ONE-TIME CREDENTIAL SETUP
1. In Cloudflare, open the biocore-solution Worker > Settings > Builds.
2. Under API token for external CI/CD, create a token limited to this Worker.
3. Store the token as a GitHub Actions repository secret named
   CLOUDFLARE_API_TOKEN in ctr-alt-i/Biocore-website.
4. Push the workflow to main and confirm the first deployment succeeds.

The token must never be committed, printed in logs, or pasted into chat.
The account ID is public configuration and is pinned in the workflow and
wrangler.jsonc. The token is provided only to the deployment step.
Cloudflare's separate Git integration is not needed for this workflow.

AUTHENTICATION
GitHub and Cloudflare do not need matching login email addresses.
The repository remains owned by ctr-alt-i. Its existing GitHub CLI and SSH
credentials can manage the repository independently of browser sign-ins.
Creating another GitHub account does not move or grant access to this repo.

LOCAL CHECKS
  npm ci
  npm run check
  npm run build
  npx wrangler deploy --dry-run

MANUAL DEPLOYMENT
Use the project's existing BioCore Wrangler profile and confirm the account:
  npx wrangler whoami
  npm run deploy
  node scripts/verify-deployment.mjs

PUBLIC FILES AND INQUIRIES
The build publishes only the HTML pages, assets, security headers, robots.txt,
and sitemap.xml from dist/. It excludes source-control metadata, credentials,
dependencies, documentation, review images, scripts, and the legacy PHP handler.
The contact form prepares an email draft locally for mv@biocoresolution.us;
visitors review and send it in their own email app. The site does not send mail.

GitHub Pages is a separate deployment and does not update the Cloudflare site.
For Cloudflare deployment results, use the Deploy BioCore to Cloudflare workflow.
